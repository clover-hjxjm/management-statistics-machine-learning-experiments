# 管理统计与机器学习实验

本仓库保存“管理统计与机器学习”课程的两个 R 语言实验，内容包括电商 A/B 测试、置换检验、Bootstrap 区间估计，以及用户满意度的均值和比例参数估计。

## 运行环境

- Windows
- R 4.4.1
- RStudio
- 仅使用 R 基础包及随 R 安装的 `stats`、`graphics` 和 `grDevices` 功能

## 文件结构

```text
管理统计与机器学习实验/

```

## 实验一：电商 A/B 测试与重抽样推断

文件：[test_1.R](管理统计与机器学习实验/test_1.R)

实验使用负二项分布模拟 A、B 两组用户点击次数，每组包含 1000 名用户。A 组理论平均点击量为 5.2，B 组为 5.8，负二项分布的形状参数设为 4。

主要步骤包括：

1. 计算两组点击次数的样本均值、样本标准差、均值差和相对提升。
2. 执行 10000 次无放回置换，构造零假设下的均值差分布，并计算带加一修正的右尾置换检验 p 值。
3. 在 A、B 两组内分别执行 10000 次有放回 Bootstrap 重抽样，估计均值差的双侧 95% 置信区间、单侧 95% 下限和 Bootstrap 标准误。
4. 绘制两组点击次数分布、置换零分布和 Bootstrap 均值差分布。

代码设置了固定随机种子，因此在相同 R 版本和随机数设置下可以复现实验结果。

## 实验二：电商用户满意度参数估计

文件：[test_2.R](管理统计与机器学习实验/test_2.R)

实验读取包含 200 条用户记录的 `ecommerce_survey.csv`，分析字段为 `satisfaction_score`，评分范围为 1 至 10 分。

主要步骤包括：

1. 检查样本量、缺失值、字段类型和评分范围。
2. 计算样本标准差。
3. 使用单样本 t 区间估计总体平均满意度及其 95% 置信区间。
4. 将评分大于 8 的用户定义为高满意度用户，计算其人数和样本比例。
5. 使用带连续性校正的 `prop.test` 估计高满意度比例的 95% 置信区间。


## 实验结果概览

在当前固定随机种子下，实验一得到 B 组相对 A 组约 10.865% 的样本均值提升；加一修正后的置换检验 p 值约为 0.000300，Bootstrap 双侧 95% 置信区间为 `[0.259, 0.878]` 次/用户。

实验二的当前数据分析结果为：平均满意度 7.1385 分，其 95% 置信区间为 `[6.9721, 7.3049]`；高满意度用户共 49 人，占 24.50%，比例的 95% 置信区间约为 `[18.83%, 31.17%]`。
