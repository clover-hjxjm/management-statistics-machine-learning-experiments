# 实验三：贝叶斯方法在管理预测中的应用

`test3.R` 根据“贝叶斯估计－第四章”中的管理预测案例编写。实验模拟零售企业的月度销售数据，并使用贝叶斯线性回归估计广告投入和节假日对销售额的影响。

## 运行环境

- Windows
- R 4.4.1
- RStudio
- 仅使用 R 基础功能与随 R 安装的 `stats`、`graphics`、`grDevices` 包

代码使用基础 R 编写四条 Gibbs 采样链，因此不需要安装 `brms`、Stan 或其他扩展包。

## 模型设定

月度销售额模型为：

```text
sales_i ~ Normal(mu_i, sigma^2)
mu_i = beta_0 + beta_1 * advertising_i + beta_2 * holiday_i
```

其中：

- `sales`：月度销售额；
- `advertising`：广告投入，模拟范围为 0 至 10 万元；
- `holiday`：节假日指示变量，节假日取 1，非节假日取 0；
- `beta_0`：基础销售水平；
- `beta_1`：广告投入每增加 1 万元带来的平均销售额变化；
- `beta_2`：节假日相对非节假日的平均销售额变化。

模拟数据使用的真实参数为 `beta_0 = 10`、`beta_1 = 2`、`beta_2 = 15`、`sigma = 4`。

## 先验分布

代码采用正态－逆伽马共轭结构：

```text
beta | sigma^2 ~ Normal(m0, sigma^2 V0)
sigma^2 ~ Inverse-Gamma(a0, b0)
```

`m0` 设为零向量，`V0` 使用较大的对角元素，使回归系数先验较为宽松。误差方差先验参数设为 `a0 = 2`、`b0 = 8`。

## 代码流程

1. 生成 100 条包含广告投入、节假日状态和销售额的模拟数据。
2. 建立贝叶斯线性回归模型并设置先验分布。
3. 运行 4 条 Gibbs 采样链，每条链迭代 6000 次，舍弃前 1000 次预热样本。
4. 计算回归系数和误差标准差的后验均值、95% 可信区间与 R-hat。
5. 预测广告投入为 5 万元时，非节假日和节假日的销售额及其 95% 后验预测区间。
6. 将四个参数的采样轨迹保存为 `Rplot_test3.jpeg`。

## 运行方法

在 RStudio 中打开 `test3.R`，将工作目录设为脚本所在目录，再点击 **Source**。图件默认保存到工作目录下的 `test3_results`。可在运行前通过 `EXPERIMENT3_OUTPUT_DIR` 环境变量指定其他目录。

也可以在 R 控制台执行：

```r
source("test3.R", encoding = "UTF-8")
```

运行完成后，控制台会输出数据概况、后验参数汇总和后验预测结果；诊断图保存在 `output_dir` 指定的目录中。

## 结果解释

- R-hat 接近 1，说明四条链对同一后验分布具有较好的一致性。
- 广告系数的后验区间若完全大于 0，表示广告投入与销售额呈稳定的正向关系。
- 节假日系数的后验区间若完全大于 0，表示节假日期间销售额通常高于非节假日。
- 后验预测区间同时包含参数不确定性和未来销售额的随机波动，可用于库存准备与营销预算安排。
